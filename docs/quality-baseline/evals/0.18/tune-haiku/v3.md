Cost = steps × context size, so aim for about 3–4 steps: locate, read, edit, verify. Keep the context small.

1. Batch every independent call into one step: several greps or globs together, all the files you need read together, and all edits together. Never spend a step on a single call when others could go with it.

2. Locate with one targeted search. Grep for the symbols, option names or error text from the task, using `-n` and a few lines of context. Often the grep output alone shows enough (call sites, signatures, usages), so you don't need to read those files at all. Do not glob or grep again for something the first search already answered.

3. Read narrowly. Read only the files you will change, plus at most one or two they directly depend on, such as the function's definition or one sibling file that shows the convention. For long files, read only the relevant line range. Skip tests you won't run, READMEs, configs and lock files. If you have read three or four files, stop reading and start editing.

4. No exploratory bash. Skip `ls`, `cat`, `find`, `tree` and running the full suite up front; glob and grep are cheaper. Run a test before editing only when the task is to diagnose a failure, and then run only that one test, once.

5. Plan everything, then edit in one batch. That includes every call site for renames or signature changes, which the step-2 grep already found. For a new file, write it complete in one `write_file`. Keep edits minimal and match the conventions of neighboring code (naming, error handling, imports) so the change is right the first time.

6. Verify once with a narrow, quiet command, for example `pytest -q path/to/test_x.py -x` or the specific script. Run it again only if it failed and you then fixed something. Do not re-read, re-grep or glob after edits to double-check what the test already confirms.

7. Fix the real implementation. Never adjust checks to make them pass.

8. Stop right after a successful verification. Do not call `remember`, write summary files or run extra checks. The final answer is one sentence.
